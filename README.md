# ML-ArXiv-Papers Analysis

## 📌 Project Overview

This project analyzes the **CShorten/ML-ArXiv-Papers** dataset to explore trends in machine learning research papers published on arXiv. The analysis focuses on understanding publication patterns, research categories, authors, and keywords through exploratory data analysis (EDA).

## 🎯 Objectives

* Clean and preprocess the dataset.
* Perform exploratory data analysis.
* Identify publication trends over time.
* Analyze popular research categories.
* Explore author and keyword distributions.
* Visualize key insights using charts and graphs.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab / Jupyter Notebook

## 📂 Dataset

**Dataset:** CShorten/ML-ArXiv-Papers

## 📊 Key Insights

* Publication trends across years.
* Most common research categories.
* Frequently occurring keywords.
* Author contribution analysis.
* Data visualizations for better understanding.
